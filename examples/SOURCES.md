# Sources used for the demo reports

Single files fetched from `raw.githubusercontent.com`, pinned to release tags, by `scripts/fetch_demo_sources.sh`
(no repository was cloned, nothing was compiled). The reports quote short single lines from these files as snippets, for illustration.
Each project keeps its own licence; the source files themselves are not redistributed here.

| Project | Tag | Licence | Files scanned |
|---|---|---|---|
| [redis/redis](https://github.com/redis/redis) | 7.2.4 | BSD-3-Clause | `src/`: Makefile, ae.c, ae_epoll.c, ae_select.c, anet.c, config.h, debug.c, util.c, server.c, bio.c, networking.c, rdb.c, syncio.c, setcpuaffinity.c, setproctitle.c, atomicvar.h, cluster.c, latency.c, zmalloc.c, monotonic.c, fmacros.h |
| [libuv/libuv](https://github.com/libuv/libuv) | v1.48.0 | MIT | `CMakeLists.txt`; `src/unix/`: linux.c, qnx.c, core.c, fs.c, thread.c, proctitle.c, procfs-exepath.c, random-getrandom.c, sysinfo-memory.c, sysinfo-loadavg.c, signal.c, process.c, posix-hrtime.c |
| [htop-dev/htop](https://github.com/htop-dev/htop) | 3.3.0 | GPL-2.0-or-later | configure.ac, Makefile.am, Affinity.c, Compat.c; `linux/`: Platform.c, LinuxProcessTable.c, LinuxMachine.c, LinuxProcess.c, SystemdMeter.c, LibSensors.c, CGroupUtils.c, PressureStallMeter.c, ZramMeter.c |

These are subsets (a few files each), so the counts describe those files only, not the whole project.
Note on libuv: it already ships a QNX backend (`src/unix/qnx.c`), included here on purpose; it shows what a finished port of the Linux-specific
parts looks like next to the Linux backend (`linux.c`) that qnxport flags.

Each folder contains `terminal.txt` (the terminal output), `qnxport-report.md|json|sarif`, and for redis a `scaffold/` generated by `qnxport scaffold`.
Regenerate with `sh scripts/fetch_demo_sources.sh` then `sh scripts/run_examples.sh`.
